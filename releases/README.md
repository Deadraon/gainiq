### What's included
- ✅ Paytm Payment Gateway integration (test/staging mode)
- ✅ WebView-based hosted checkout (UPI, Cards, Net Banking, Wallet)
- ✅ Subscription activation via Firebase on payment success
- ✅ Coupon redemption system
- ✅ AI Diet & Workout plan generation (Gemini)
- ✅ Admin panel for subscription management

### How to install (Android)
1. Enable **Install from unknown sources** in your Android settings
2. Transfer `gainiq-v1.0.0-paytm-debug.apk` to your device
3. Tap to install
